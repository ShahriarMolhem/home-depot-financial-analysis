# Home Depot Historical Data Pack

This folder contains extracted historical **reported** values in `historical-financials.csv`. See [historical financial performance](../reports/financial-performance.md) and [validation](../quality/historical-validation.md).

**Original sources:** FY2025 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/354950/000162828026019436/hd-20260201.htm) (2025, 2024, 2023 earnings, cash flow, and 2025/2024 balance sheets); FY2023 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/354950/000035495024000062/hd-20240128.htm) (2021–2023 income/cash flow and 2022/2023 balance sheets); FY2022 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/354950/000035495023000059/hd-20230129.htm) (2021 balance sheet). See [primary-source register](source-register.md).

**Signs:** Capex, dividends, repurchases, and acquisitions are shown as signed cash outflows. Financial ratios should be *calculated* rather than added as standalone reported columns. Diluted EPS is dollars per share and shares are in millions, not dollar values.

**Limitation:** The Excel companion model is a separate deliverable and may not yet be present in this GitHub branch. The source CSV and reports are published now so the data is inspectable. Do not imply that a workbook or presentation has already been uploaded here.
